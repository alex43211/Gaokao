### 近 3 年投档线数据说明

- **覆盖范围**：内地 31 个省（区、市）；港澳台不参加内地统一高考，单独说明。
- **分数线**：各省教育考试院公布的**分批次录取控制分数线**。
- **报考人数**：官方公布的报名（或实际参加统考）人数，**逐年标注统计口径**。
- **口径自适应**：
  | 高考模式 | 省份 | 人数显示 | 分数线分列 |
  | --- | --- | --- | --- |
  | 3+3 | 北京、天津、上海、浙江、山东、海南 | 考生人数 | 单一分数 |
  | 3+1+2 | 其余 23 省（区、市） | 物理类 / 历史类考生人数 | 物理类 / 历史类 |
  | 老高考 | **新疆、西藏** | 理科 / 文科考生人数 | 理科 / 文科 |
- ⚠️ **新疆、西藏 2026 年仍是老高考（文理分科）**，新疆计划 2027 年才切换至 3+1+2。
- 分科类人数仅在官方公布时呈现；未公布的年份仅显示总量并注明「该年未公布分科类人数」。

## 志愿填报四步法

1. **问家庭** —— 家里有没有行业资源？能支持多长的求学周期？先分流再决策。
2. **看就业** —— 不看宣传册，看这个专业中间 50% 毕业生 5 年后的真实去向与薪资中位数。
3. **选城市** —— 同等分数下优先发达城市，城市是分数的隐形放大器。
4. **拉梯度** —— 冲、稳、保三档拉开梯度，避免滑档与高分低就。

## 技术说明

纯静态站点，无须任何后端与构建步骤：

- 原生 HTML / CSS / JavaScript，开箱即用
- [ECharts](https://echarts.apache.org/) 绘制全国地图与可视化图表
- 数据以 JS 文件形式内嵌（`assets/js/data-*.js`），首屏即可离线渲染
- 站点导航与页脚由 `assets/js/theme.js` 的 `buildShell()` 统一注入，多个页面共用一套壳

## ⚠️ 数据免责声明

全站数据分两类，请区分对待：

**① 真实数据**（来源为各省教育考试院 / 教育部等官方公开信息）
- 各省近 3 年（2024—2026）各批次录取控制分数线与报考人数
  （数据源：省考试院公布的控制分数线与报名/参考人数，经中国教育在线、人民网、

- 本科专业的**选科要求**（依据教育部《普通高校本科招生专业选考科目要求指引（通用版）》）

**② 演示数据**（仅用于功能演示，不可作填报依据）
- 地图底色的考生规模色阶、院校「参考档」分数、就业与薪资数据
- `data-provinces.js` 中的省情点评、优势产业等内容

即便为真实数据，各省统计口径并不完全一致（报名人数 / 实际参加统考人数），
批次名称与数量也逐年调整，**填报时务必以本省教育考试院当年《招生计划》
与高校招生章程为准**。本站不承担因使用本站数据产生的任何后果。
