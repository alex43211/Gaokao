## 志愿填报四步法

1. **问家庭** —— 家里有没有行业资源？能支持多长的求学周期？先分流再决策。
2. **看就业** —— 不看宣传册，看这个专业中间 50% 毕业生 5 年后的真实去向与薪资中位数。
3. **选城市** —— 同等分数下优先发达城市，城市是分数的隐形放大器。
4. **拉梯度** —— 冲、稳、保三档拉开梯度，避免滑档与高分低就。

## 技术说明

纯静态站点，无须任何后端与构建步骤：

- 原生 HTML / CSS / JavaScript，开箱即用
- [ECharts](https://echarts.apache.org/) 绘制全国地图与可视化图表
- 数据以 JS 文件形式内嵌（`assets/js/data-*.js`），首屏即可离线渲染
- 站点导航与页脚由 `assets/js/theme.js` 的 `buildShell()` 统一注入，多个页面共用一套壳
